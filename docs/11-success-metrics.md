# Succescriteria en metingen

## Procesmetingen

| Meetpunt | Pilotdoel |
| --- | --- |
| Intake invullen | Minder dan 2 minuten |
| Eerste concept klaar | Minder dan 5 minuten na intake |
| Salescontrole | Minder dan 10 minuten |
| Opvolging verstuurd | Dezelfde werkdag |
| Geldige AI-output | Minimaal 90 procent |

## Kwaliteitsmetingen

| Meetpunt | Pilotdoel |
| --- | --- |
| Juiste samenvatting | Minimaal 80 procent zonder grote wijziging |
| Productselectie behouden | Minimaal 70 procent |
| Verzonnen productfeiten | 0 |
| Saleswaardering | Minimaal 7 van 10 |

## Verkoopmetingen

| Meetpunt | Eerste hypothese |
| --- | --- |
| Buyer room geopend | Minimaal 50 procent |
| Productlink aangeklikt | Minimaal 25 procent |
| Buyer room gedeeld | Meten, nog geen doel |
| Vervolgactie gebruikt | Minimaal 20 procent |
| Vervolgafspraak | Minimaal 10 procent |

## Interpretatie

De eerste pilot heeft weinig leads. Gebruik de cijfers daarom vooral om problemen en gedrag te ontdekken.

Trek nog geen harde commerciële conclusies uit tien leads.

## Belangrijke kwalitatieve vragen

Vraag sales:

- Bespaart dit tijd?
- Past de selectie bij het gesprek?
- Zou je dit opnieuw gebruiken?
- Welke informatie ontbreekt?
- Welke delen pas je vaak aan?

Vraag ontvangers waar mogelijk:

- Was de selectie relevant?
- Kon je de informatie makkelijk delen?
- Was de vervolgstap duidelijk?
