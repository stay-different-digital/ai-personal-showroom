# Voorbeeld: `brand.json`

Dit is voorbeelddata. Laat officiële kleuren, logo's en lettertypen door Zuiver controleren.

```json
{
  "brandId": "zuiver",
  "name": "Zuiver",
  "tagline": "",
  "logo": "/assets/brands/zuiver/logo.svg",
  "primaryColor": "#111111",
  "secondaryColor": "#F2EFE9",
  "backgroundColor": "#FFFFFF",
  "textColor": "#111111",
  "toneOfVoice": [
    "modern",
    "inspirerend",
    "toegankelijk"
  ],
  "visualStyle": [
    "veel witruimte",
    "grote interieurbeelden",
    "rustige typografie",
    "editorial opmaak"
  ]
}
```
